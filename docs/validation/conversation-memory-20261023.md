## Operating limits

Only new locally captured native user prompts are automatic. Assistant replies are
recorded at Stop but not auto-interpreted as authoritative claims. Project/global
conventions require explicit review; task-only changes produce no long-term Memory
source. Existing history requires a scoped page action (<=200 unprocessed user
messages); exact Event analysis also supports a single assistant proposal, which
cannot acquire human provenance. There is no offline capture delivery queue.

Processing is asynchronous and uses configured model access. It is not a
synchronous pre-tool Guard or an assurance that every message becomes Memory.
Hindsight is historical/non-authoritative and current Authority remains primary.
This result does not establish universal native context injection of every memory
type or complete P4 benefit/P6/P7 release acceptance. Keep the schema-13 backup
and preserve post-backup data separately before any recovery; there is no
schema-14 downgrade migration.
