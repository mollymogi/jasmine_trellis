## 1. 本轮范围与完成标准

本轮先收拢已交付的单机可用能力，不宣称完整 V1。目标是让候选提交、
测试证据、发布版本、数据库版本、日常入口、备份与回滚说明对应同一个明确版本。

以下扩展保留为后续事项，不在本轮顺手实现：

- 自然语言“不要修改某文件”生成、批准并执行 HARD/DENY 文件保护规则。
- P5 在线心跳、离线同步、冲突处理和跨设备接力。
- P4 记忆收益实验；既有实验停止状态不变。
- 完整 P7 Scenario Runner、VC-01～VC-30、综合长任务和全 V1 发布门禁。

不扩展这些能力不等于关闭它们的缺口。原生日常采集/注入仍按实际开放状态标注；
不得用手动预置规则或隔离 Gate 冒充日常自然语言全链已接通。
